# Requisitos obrigatórios PNTP 2025 - escopos selecionados

Fonte-base: `\\SRV-FV01\Desenvolvimento\Dev\referencias\Cartilha-PNTP-2025-exata.md`

Escopo deste arquivo: requisitos com **Classificação: Obrigatória** para **Poder Executivo**, **Consórcio Público**, **Estatais**, **Poder Legislativo** e **Tribunal de Contas**. O texto abaixo é um checklist operacional derivado da cartilha; os documentos originais devem ser consultados para fundamentação, disponibilidade detalhada e regras de aplicação.

## Resumo por escopo

- Poder Executivo: 57 requisitos obrigatórios
- Consórcio Público: 27 requisitos obrigatórios
- Estatais: 73 requisitos obrigatórios
- Poder Legislativo: 58 requisitos obrigatórios
- Tribunal de Contas: 55 requisitos obrigatórios
